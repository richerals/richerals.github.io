Nonlinear systems

Magnetic pendulum

A damped particle moves on a potential landscape generated by fixed magnets beneath the plane. Trajectories emerge from RK4 integration of the coupled ODEs—not from scripted animation.

Drag magnets or the bob · Add magnets · Run to integrate

Parameters

Simulation

Paused — adjust layout, then Run

Equations

2D small-angle model (particle in the plane):

ẍ + b ẋ + x = Σ (xₙ − x) / (|xₙ − x|² + h²)^(5/2)

Integration: classical RK4, fixed Δt per substep.

Notes

  • Monopole magnets in a plane with softening height h; restoring term models the pendulum spring / small-angle limit.
  • Sensitive dependence on initial position and magnet layout illustrates chaotic dynamics.
